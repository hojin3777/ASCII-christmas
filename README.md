# ASCII Christmas

모바일 화면(`1080×2316` FHD+ 비율)에 최적화된 단일 터미널 그리드 기반 3D ASCII 크리스마스 트리 웹 페이지입니다.

## Live Demo

- **Web**: https://hojin3777.github.io/ASCII-christmas

## 주요 특징

- **레트로 터미널 부팅 스크린**: 검정 배경 위 초록색 터미널 로그와 BIOS 비프음 출력 후, 하드 컷으로 메인 시퀀스가 시작됩니다.
- **통합 단일 ASCII 그리드 (`106×142`)**: 눈, 바닥 적설, 3D 회전 트리, 오너먼트, 상단 필기체 텍스트, 하단 타이머까지 모두 동일한 단일 폰트(`D2Coding` / `Cascadia Code`)와 Z-버퍼 그리드 안에서 렌더링됩니다.
- **단계별 애니메이션 (흰색 → 고유 색상 전환)**
  - 다양한 문자(`+`, `*`, `。`, `.`, `·`, `,`)로 구성된 다층 눈송이 낙하 및 하단 원형 눈더미 적설
  - 밑둥부터 4단으로 자라며 천천히 상시 회전하는 3D ASCII 트리
  - 주황색·빨간색 이중 나선 줄 오너먼트(갈란드) 및 구·별·양말 3D 오너먼트
  - 꼭대기 별, 필기체 ASCII `Merry` / `christmas`, 한국 표준시(KST, UTC+9) 기준 `DD:HH:MM:SS` 크리스마스 카운트다운
- **Web Audio API 칩튠 사운드**: 별도 음원 파일 없이 실시간 합성으로 *We Wish You a Merry Christmas* 레트로 칩튠이 재생되며, 우측 상단 버튼으로 소리 ON/OFF 및 처음부터 다시 재생할 수 있습니다.

별도 빌드 과정 없이 정적 파일만으로 동작하며, GitHub Pages를 통해 배포됩니다.
